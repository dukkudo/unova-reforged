# Unova Reforged Prototype

This is the first technical prototype for a 3D HD-2D Pokémon-inspired project.

## Current prototype

- 3D ground and lighting
- Free, non-tile-based trainer movement
- Smooth camera follow
- Crisp nearest-filtered pixel sprites without a full-screen pixelation filter
- Animated procedural trainer sprite frames
- Small 0.5-unit world tiles used for placement and collision footprints
- Trees occupying 2x2 tiles with matching invisible collision boxes
- Tiled pixel-art grass ground
- Sprite-based trees and clouds
- Wind-reactive trees and moving clouds

## Running

Install Godot 4, then import this folder as a project and run `main.tscn`.

Controls: WASD movement.
